MS-01 · LEARNINGDone

A little maths adventure

The current Number Quest game, preserved in this repository.

  • Four operations and ranges from 1–10 to 1–100.
  • Hugo / Iggy profiles, ten-question rounds and leaderboard.
  • Optional timer, sounds and one-second answer-only correction.

MS-02 · TRUSTDone

Make every point verifiable

The server now issues questions, checks answers once and records the completed round. Live version 16 deployed with its migration.

  • Issue questions and validate answers on the server.
  • Bind each question to a player, round and expiry.
  • Reject replayed answers and award each result once.

Verified locally and against the live start, leaderboard and legacy rejection routes. Independent child identity is the next milestone.

MS-03 · PARENTSIn Progress

A genuinely separate parent space

  • Parent ChatGPT identity plus a separate access code and protected server routes.
  • Player PIN sessions for Hugo and Iggy, bound to each quiz round.
  • Reward rate, daily child caps, approved withdrawals and pause control.

Code and migration prepared; finish parent unlock and set both PINs on the live site.

MS-04 · REWARDSFuture

One pot. Separate balances.

Parent-managed Cashu, with an internal claim for each child until withdrawal.

  • Atomic ledger: available, reserved and paid balances.
  • Idempotent awards and daily caps enforced on the server.
  • Distinguish points, reserved sats and sats actually withdrawn.

Ready when: concurrent awards cannot overspend the pool, and every balance reconciles.

MS-05 · CASHUFuture

Test the complete money journey

  • Connect a test mint; account for mint fees.
  • Protect proofs, back up state and recover interrupted operations.
  • Parent-approved export or withdrawal before a small funded pilot.

Ready when: funding, earning, withdrawal and recovery reconcile with no duplicate spends. Real funds remain off until reviewed.

MS-06 · EXPERIENCEFuture

A sketchbook that grows with them

  • Minimal hand-drawn game interface with crisp, legible numbers.
  • Blue and orange accents; mobile layout and keyboard checks.
  • Languages, science and geography on the same scoring system.

Ready when: each subject has reviewed age-appropriate questions and works with verified scoring.
